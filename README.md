# 香港四日自由行網站

此 repository 是「香港四日自由行」網站的唯一發佈來源，GitHub Pages 發佈的內容由根目錄的 `index.html` 提供。

## 更新規則

1. 一律在本 repository 的 `main` 分支更新並推送；不要把 `D:\MorrisData\travel\20261106香港` 本機旅行資料夾視為發佈來源，該資料夾沒有 Git metadata。
2. 本專案目前是單檔靜態網站。修改行程文字、導航連結、Leaflet 地圖資料或頁腳日期時，直接更新根目錄 `index.html`，並確認同一景點在「每日行程」、「地圖導覽」與互動地圖三處一致。
3. 涉及交通、營業日／時間、票價或景點開放狀態時，先查官方來源；不要沿用舊旅遊文章。將查核日期與來源摘要寫入決議表，並在行程中保留出發前複查提示。
4. 更新後至少執行 HTML 結構檢查、搜尋新舊行程名稱確認沒有遺漏，檢視 Git diff，再 commit 與 push。
